BUILD APK (no Android Studio needed)
1. Make free GitHub account. New repo (private ok).
2. Upload ALL files from this folder (keep .github folder). Commit to main.
3. Repo > Actions tab > "Build APK" runs (about 5 min). Green = done.
4. Click run > Artifacts > vehicle-papers-apk > download zip > unzip > app-debug.apk
5. Send apk to phone. Tap it. Allow "install unknown apps". Install.
6. Open app. Allow notifications. Settings > Test alert to check.
